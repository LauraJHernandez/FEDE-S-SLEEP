# Fede's Sleep

Aplicación web progresiva (PWA) para registrar sueño, lactancia, pañales, síntomas y notas.

## Instalación en iPhone
1. Publica el contenido de esta carpeta en un hosting HTTPS (por ejemplo, GitHub Pages o Netlify).
2. Abre la dirección publicada en Safari.
3. Pulsa Compartir → Añadir a pantalla de inicio.
4. Abre Fede's Sleep desde el icono añadido.

## Instalación en Android
Abre la dirección HTTPS en Chrome y elige Instalar aplicación / Añadir a pantalla de inicio.

## Privacidad y copias
Los registros se guardan en el almacenamiento local del navegador del dispositivo. Usa Estadísticas → Exportar datos para guardar una copia JSON. Si borras los datos del navegador, puedes perder los registros. La importación reemplaza los datos actuales.

## Importante
La app es un diario personal y no sustituye la valoración pediátrica. Las sugerencias de sueño son orientativas; alimenta al bebé a demanda y sigue las recomendaciones de sueño seguro.
